# fr55 documentation

**fr55** is a collection of Connect IQ watchface apps and editor tooling for the
**Garmin Forerunner 55** (`fr55`, 240×240 MIP display), written in Monkey C.

## What's inside

- **`apps/`** — buildable watchface apps: `hands`, `minimalism`, `maximalism`,
  and `timezones`.
- **`packages/extensions/vscode/`** — Monkey C/Jungle VS Code extension.
- **`packages/extensions/zed/`** — Monkey C/Jungle Zed extension.
- **`scripts/`** — Monkey C format/lint helpers.

## Sections

- **Getting started** — build and preview a watchface app.
- **Concepts** — Connect IQ and the Monkey C language.
- **Guides** — the watchface apps and the editor extensions.
