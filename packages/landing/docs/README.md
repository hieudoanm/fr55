# fr55 documentation

**fr55** is a collection of Connect IQ watchface apps for the **Garmin
Forerunner 55** (`fr55`, 240×240 MIP display), written in Monkey C.

## What's inside

- **`apps/`** — buildable watchface apps: `hands`, `minimalism`, `maximalism`,
  and `timezones`.
- **`assets/design/svg/`** — 16 watchface design previews.
- **`packages/landing/`** — this site, deployed to GitHub Pages.

Editor tooling for Monkey C (VS Code/Zed extensions, `monkey` CLI) lives in the
companion repo `hieudoanm/monkey`.

## Sections

- **Getting started** — build and preview a watchface app.
- **Concepts** — Connect IQ and the Monkey C language.
- **Guides** — the watchface apps and the design gallery.
