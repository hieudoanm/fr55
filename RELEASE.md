## Monkey C for VS Code — latest build

Language support for Garmin Connect IQ Monkey C and Jungle manifests:
syntax highlighting, diagnostics, formatting, snippets, and a
runtime-preview task. Companion Zed extension lives in the same repo.

### Install

Download `monkey-c.vsix` from the assets below and install via
**Extensions → Install from VSIX** in VS Code.
