Features

Monkey C & Jungle

Language support for .mc, .mb, .mcgen, and .jungle files with syntax highlighting and editor configuration.

Formatting

Built-in document formatter for Monkey C and Jungle, with a Format Document command for quick cleanup.

Theme & Icons

Includes a Monkey C dark color theme and file icon theme to make Connect IQ projects easier to scan.

Simulator Preview

Monkey C: Runtime Preview (Simulator) builds and launches the nearest Connect IQ package using your local SDK and developer key.
