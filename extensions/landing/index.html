Install for Zed

Install for Zed

Zed extensions are loaded from source — there is no .vsix to download.

1. Load the extension

  1. In Zed, open the Extensions page and choose Install Dev Extension.
  2. Select extensions/zed from this repository.
  3. Make sure extensions/zed/grammars/tree-sitter-jungle is committed and pushed to master (Zed fetches grammars by Git revision).

2. Install the CLI helpers

cd extensions/zed
./scripts/install.sh

This symlinks monkey-c-format and monkey-c-preview into ~/.local/bin (or $MONKEYC_BIN_DIR) so Zed's external formatter and tasks can find them.

3. Configure the formatter

{
  "languages": {
    "Monkey C": {
      "formatter": {
        "external": {
          "command": "monkey-c-format",
          "arguments": ["--lang", "monkeyc"]
        }
      },
      "format_on_save": "on"
    },
    "Jungle": {
      "formatter": {
        "external": {
          "command": "monkey-c-format",
          "arguments": ["--lang", "jungle"]
        }
      },
      "format_on_save": "on"
    }
  }
}

4. Run Runtime Preview

Open task: spawn (cmd-shift-p) → choose Monkey C: Runtime Preview or Monkey C: Build PRG.
